# 近期综述推荐入口（2026-11-12）

本轮只新增十个方向综述的开头阅读书目：23 篇不同综述、24 个方向条目。选择以方向相关性、2024—2026 年发表记录和引用积累共同判断，不声称穷尽引用最高的论文。低引用新稿标为近期补充。较早经典文献保留在原正文和参考文献中。

- `selection.json`：推荐去向、用途、排除理由与日期精度。
- `citation-snapshot.json`：逐篇 OpenAlex work ID、准确查询、引用量、日期及原响应 SHA-256。
- `primary-source-checks.json`：一手来源、阅读范围、姓名/日期与聚合器冲突处理。
- `retrieval-audit.json`：来源尝试，宽泛目录命中与 28 个范围内候选分开；Semantic Scholar HTTP 429 如实保留。
- `coverage-receipt.json`：固定证据分片覆盖；检索者不负责纳入判断或终审。
- `local-corpus-checks.json`：当前 210 份原始 Markdown 的十方向 rg 核对。
- `page-ledger.json`：前后综述指纹；原正文、参考文献、历史查询与实质复核日期逐键不变。
- `independent-content-review.json` 与 `independent-implementation-review.json`：未参与撰写的独立审阅，属于 same-family provisional。

推荐书目单独保存核对日期，不将其计入历史方法证据的查询数量。新增条目没有改变正文技术结论，因此未把本次编辑日期覆盖到整篇 reviewedAt；未来据此补写正文时，需按既有综述流程更新相关引用与检索台账。

正式在线日优先。无法从一手来源核实在线日时，显示已确认卷期并保留月精度，绝不从 Crossref created 或 OpenAlex 日期猜测。HEP/Springer 两个平台的首次在线和后续版本记录分别保留。

原始 API 响应、基线快照、生成提示、浏览截图/PDF、部署回执留在忽略目录中；公开提交保留可复核的紧凑记录。本轮未改简报或邮件版本身份，不发送既有简报。
