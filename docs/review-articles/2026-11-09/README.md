# 按领域重组综述文章

本轮承接读者对“仍有 AI 味、像统一讲义”的反馈，重组全部十个方向综述。结构改动与表达改动同时进行，不以禁词、压缩比例或检测分数评价文章。

## 正文组织

- 三维重建：时间参数化、对象与遮挡、构建成本、传感器、仿真有效性分别展开；同一方法的演化与分类合并。
- 协同驾驶：沿共享表示、消息选择、接收校正与联合行动组织，新增管线图与条件表。
- 雷达：按概率地图、当前占据、运动预测、测量解释等并列任务组织，避免单线替代史。
- 端到端驾驶：围绕规划表示、候选生成/选择、训练分布与执行协议展开。
- 驾驶智能体：按语言接口、工具、记忆、动作依赖和运行时组织。
- 世界模型：分别讨论潜空间控制、视频/三维生成、评分记忆与交互环境。
- 动态场景：区分空间编码、历史融合、晚到校正、未来预测和对象记忆。
- LiDAR 异常：把未知定义、训练暴露、评分、对象分组、基准协议和域变化接起来。
- 测试：区分失效搜索、自然事件率估计、回归诊断和现实迁移。
- 安全：把威胁模型、物理输入、学习/语言接口、持久状态及恢复连起来；平台和权限条件保留在相关实验旁。

结构版本 2 允许不同章数，`covers` 保留六类编辑覆盖检查；旧六节 ID、标题 ID、问题与结尾片段通过 `legacyAnchors` 定位。取消统一情景开头、每章导语和自动结尾条目。每节引文按当前正文重分，未展开的原有文献明确列为延伸阅读。436 条原始引用对象、历史来源审计与实质复核日期保持不变。

三幅原创综合图表达参数化、通信位置与雷达任务关系。图是依据原论文整理的机制示意，不是实验数据或论文原图。每张图保存真实 SVG 尺寸、SHA-256 与来源；作者和独立审阅者实际打开图像。17 篇已收录一手来源被定向重开，另记录审阅中对 SCAPE 区间的澄清；本轮没有声称重新检索全部方向或复现实验。独立复核适用仓库的 JSON/Markdown 合约，借鉴已安装 research-lit、comm-lit-review 与 citation-audit 的证据要求，并非运行 LaTeX 投稿的逐条 bib 审计。

## 核验与记录

`evidence/` 保存定向来源覆盖和有依据的澄清；`local-corpus-checks.json` 保存对当前 210 份 Markdown 执行的十方向真实 rg 检索，原历史查询日期未回填。`page-ledger.json` 保存修改前后文件指纹、章节与旧锚点映射、图指纹和最终独立审批。

`reviews/` 保留首轮请求修改与二轮通过记录。首轮发现了重复段落、机制遗漏、引文错位、SCAPE 区间表述以及 SVG 根尺寸/打印问题；修订后重新读取并绑定。审阅由未参与撰写的同模型家族代理完成，标记 same-family provisional。测试篇首轮曾在并发修改期间捕获到较新的指纹，二轮明确记录了时间差，最终以完整重读后的二轮通过为准。

新测试覆盖自由章数下的分析维度、历史锚点、引用归属、SVG 根尺寸与部署资源验证。桌面与 390 px 检查覆盖全部十篇、目录、引文、搜索、原图、表格、公式和打印。打印同时移除侧栏占位，避免正文偏右或空白首页。

`npm run review:preflight`、`npm run validate`、`npm test` 和 `TZ=UTC GITHUB_ACTIONS=true npm run build` 统一运行。测试 359 项通过、7 项既有条件跳过，另有一组依赖外部 pickle 的测试由运行器明确省略。构建保留 262 个 HTML 路径，搜索 JSON 与 gzip 解压后相同。

部署与线上验证单独记录于本地 release receipt，并以最终提交的 GitHub 工作流为准。论文报告、简报、Idea 判定和订阅名单未改；不重发简报邮件。用户已有的 literature-review-workflow upstream/syncedAt 改动保留在工作区，未纳入本轮提交。

`prompts/` 保存修改开始时由仓库命令生成的提示快照；本轮对固定六章和统一开篇的改动已同步到当前生成器，不回写这份历史输入。正式预览完成 24 项浏览检查；三维重建与 LiDAR 打印检查确认首页有正文、全部章节和 42/29 条书目可读取。实现复核记录的十个 JSON 原始哈希早于最终审批写入；将 `independentReview` 还原为原 pending 元数据后，全部精确匹配，正文与图指纹也与二轮审阅一致。
