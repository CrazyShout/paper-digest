# 经典工作与综述覆盖补充

本轮针对十个方向检查此前近期更新遗漏的方法源头、基准和综述分类。共补入45条引用：15篇综述及30篇方法、数据集和问题定义工作。综述总引用记录为436条；其中部分跨方向引用会重复，不能把方向内记录总数当成不同论文数。

检查从互补综述的分类、历史和参考文献章节开始，再回到原论文。新增内容直接进入scope/evolution/taxonomy：读者可以先沿综述阅读路径建立结构，再追溯原始机制。原有六节ID、近期方法分析、论文报告、简报和Idea判定保留。

- `selection.json`：父流程对59个定向候选作出选择，45条补入、13条已有记录保留；OpenMax作为图像开放集分类的相邻源头保留在候选审计，本篇暂不增加详述。
- `retrieval/*/evidence.json`：实际阅读深度、章节定位、文献版本、原论文出处和来源指纹；原始网页/PDF缓存只在本地保留。
- `authoring/`：各组修改范围与前后指纹。
- `independent-review/`：新增引用、正文与增量台账的独立复核，实际修正单独记录。属于同模型家族复核，不是人工终审或实验复现。
- `coverage-matrix.json`：各方向的综述锚点、方法脉络与明确覆盖边界。
- `final-bindings.json`、`checks-summary.json`：最终审批与验证结果；发布后的线上结果另存本地release-receipt，GitHub工作流保留远端记录。

原有查询族与本库rg结果不回写。新增“经典工作、综述分类与引文追溯”查询族，将本轮有出处的候选放入同一可复核入口；宽泛API/Web返回不算作已读论文。正式论文与arXiv保留双入口。版本差异（例如MAEAD v1/v4作者变化）、综述中的引用或章节错误均回到一手记录处理。

覆盖是按当前问题范围作出的判断，不是所有历史文献已穷尽。动态占据使用的2025信息融合综述实际阅读版本覆盖至2024；2026新论文已在当前综述中，补查的部分2026综述尚未获得足够正式全文证据，因此保留具体缺口。

本轮不改变简报内容版本，不发送新的简报广播。部署后的受保护通知工作流应确认此前版本已处理并跳过发送。
