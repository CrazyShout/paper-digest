# 综述正文与阅读排版修订

本轮重写十个方向的解释性正文，解决开篇术语过密、方法名并列、审核口吻和实验任务单挤占阅读主线的问题。各篇从具体场景说明输入、输出与困难，再解释路线怎样工作、后续方法为何改变设计。经典与近期综述仍作为阅读入口，重要结果和限制仍放在相关论述旁。

六节结构、章节 ID、436 条引用记录、原始检索记录和文献实质复核日期保持不变。摘要和结尾按各自用途重新写，不再原样重复章节内容。移出的实验安排与核验过程保存在 authoring 记录中，历史 Idea 判定未改。

页面默认收起每节参考文献和完整书目。段内引用与旧锚点仍能打开并定位书目；键盘操作、全库搜索及完整打印保留。编写规范同步取消综述必须列出实验基线、失败阈值和回退条件的要求，详细实验方案留在可选的 Idea 层。

证据记录：

- `prompts/`：开始时由仓库命令生成的方向提示快照。随后更新的写作要求见本次仓库 diff。
- `authoring/`：逐页改写原因、语义保留说明和移出主线的材料。
- `local-corpus-checks.json`：本轮实际执行的 10 次原始 Markdown 检索，分开记录文件命中、规范候选和筛除计数；历史查询日期没有回填。
- `page-ledger.json`：修改前后文件 SHA-256、正文快照指纹、公式与引用/锚点保留检查。
- `independent-review/`：未参与对应正文撰写的审阅者逐页复核，绑定其实际读取的快照。
- `browser-*/checks.json`：桌面、390 px、旧锚点、引用展开、键盘、搜索和打印检查。截图及打印 PDF 仅本地保存。

本轮是编辑性改写，没有声称重新检索站外全部文献或复现实验。独立复核由同模型家族的不同代理执行。部署后的资源校验和通知去重结果保存在本地 release receipt，并可由 GitHub 工作流核对；不重发既有简报。

独立复核中补充了 ICP、IDM、MLP、MPM、TTC 等术语解释，并澄清 NeRF 中位置、密度、方向与颜色的关系。作者清单保存送审时版本；最终文件以 `page-ledger.json` 和独立复核指纹为准。390 px 下三列及以上综述表格保留较宽文字列，在表格内部横向滚动；打印不受此宽度规则影响。

验证结果：`review:preflight`、`validate` 与正式 Pages 构建通过；`npm test` 为 352 通过、7 项既有条件跳过，另有一组依赖外部 pickle 的测试由运行器明确省略。构建保留全部 262 个历史 HTML 路径，搜索 JSON/gzip 解压后相同，281 个原始资源文件与源文件一致。最终生产预览与上线验证分别记录，不把本地构建当成部署成功。
