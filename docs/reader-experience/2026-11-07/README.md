# 公共周报阅读体验更新

这轮按不同读者各自选读的方式组织网站。十个研究方向、完整报告、经典与前沿综述和历史Idea记录均保留；不要求读者读完整期或推进同一组实验。

新增十个方向阅读页及总入口。每页按真实收录期号组织主方向与关联论文，沿用修订后的正文身份和原始期号，提供近期短评、19组跨期对照、7个可选迁移入口及13项后续阅读线索。三维重建本期没有新条目时，明确显示最近的11月1日专题；Agentic与安全方向也说明本期条目分别来自测试助手和运行时保障。

首页方向入口前置，全部本期论文继续显示。单篇报告可返回所属简报及方向页。综述中的内部引用ID仅在显示层转换为编号链接，审定的JSON与指纹保持不变。本机笔记明确标示为私人保存；公开荐文、纠错使用GitHub表单，未自动提交反馈或收集订阅兴趣。

检索方面增加可复用的`discover:screen`命令，把现有宽泛标题规则与当前方向关键词取并集。旧目录3597条标题未命中记录回放后，有44条新的词汇命中，其中42条不在旧920候选池中；这是待阅读集合，不是已选论文，也不是召回率。AgentNorm是旧标题层漏项、被其他查询找回的回归例子。抽查还发现Utility-WAM缩写缺口，因此增加WAM别名。Utility-WAM与Mamba3R仅完成本次原摘要初读，待下期全文比较；风电预测例子说明关键词命中仍会包含范围外工作。历史检索记录未回写。

证据：

- `continuity-evidence.json`：阅读说明逐字段对应原报告；`independent-content-review.json`绑定最终文本。
- `independent-implementation-review*.json`：方向归组、引用链接、搜索投影和笔记接口检查。
- `independent-publication-check-review.json`：新增方向页面进入部署字节校验，兼容旧欢迎邮件产物。
- `workflow-review.md`、`coverage-followup.json`及标题回放：真实检索缺口、待跟进线索与边界。
- `browser/`中的JSON：桌面、390px、键盘、搜索、深链接、本机存储、打印检查；截图和PDF仅本地保留。
- `checks-summary.json`、`final-bindings.json`：发布前验证。最终部署与通知结果另存在本地release-receipt，并可由GitHub工作流核对。

本轮没有修改简报、单篇报告、综述来源内容、Idea判定或收件人；没有重发简报。内容判断来自不同代理的同模型家族复核，不是读者研究或实验复现。现有本机笔记不能反映其他读者反馈，仓库外是否有采集调度仍未知。
