# 3D/4D 场景重建展示更名

导航名称改为“3D/4D 场景重建”，范围说明强调以 3D/4D 高斯为主的静态与动态重建、场景编辑和多传感器渲染。综述只改标题，正文、图、引用、历史审计和实质复核日期未变。方向 ID、路径、既有章节锚点保持稳定；旧名称保留作方向搜索别名。

配置中的 `displayLabel` 供页面、Idea 投影、生成提示以及后续邮件/飞书正文使用，`label` 保留为稳定名称。通知指纹原本包含方向名称，直接替换会让旧简报被误判为更新；本轮从稳定配置名生成相同格式的通知标签，不改冻结 baseline、发送台账、邮件排除名单或判定规则。`notification-stability.json` 记录 26 期完整快照的比对结果，全部身份与来源不变。新增回归测试确认展示改名不会重发，真实内容变化仍会触发更新，未决回执仍阻止发送。

`independent-review.json` 是未参与修改的审阅者对标题与展示代码的复核，包含最终内容指纹和边界；不是新一轮科学内容评审。`local-corpus.json` 保存实际重新执行的本库检索，历史日期未回填。原有 Idea 候选与评审记录未修改，飞书仅执行本地预览，未发布远端内容。

发布依次验证 preflight、validate、tests、正式 Pages 构建，检查桌面与390px名称、旧搜索词和路由。线上结果另存本地 release receipt，以最终提交对应的 Pages 与受保护通知工作流为准。用户已有的 literature-review-workflow upstream/syncedAt 改动保持未提交。
