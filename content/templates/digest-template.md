# 简报正文模板

这个模板用于 `content/digests/YYYY-MM-DD.md` 的正文部分。首页展示本期全部论文条目；简报页把第一节短导读放在论文列表之前，其余讨论放在列表之后。筛选与检索说明单独收在末尾的展开区域，原始 Markdown 始终完整保存。

```md
## 本期判断

用约 120–200 字说明本期有哪些具体进展，哪些论文适合对照阅读。直接写方法变化或实验发现；没有共同主线时，分别介绍相关工作即可。较长的比较分析放到后面的讨论部分。

## 筛选口径

- 说明本期为什么选这些论文，而不是同主题的其他论文。
- 区分扫描窗口与作者提交日期，并链接本期 `content/digest-audits/YYYY-MM-DD.json` 对应的公开审计入口。
- 给出可由候选台账重算的原始命中、去重候选、全文比较、排除和入选数量。
- 说明本期实际采用的优先级和排除理由。
- 用一段话保留影响覆盖面的来源限制。逐篇发表状态、代码、数据、图片及阅读范围放在对应报告中，简报只提示本期需要特别注意的情况。

## 应用场景与讨论线索

围绕实际论文写需要比较的机制、实验条件和可跟进的问题。说明适用方向，读者可以按兴趣选读；避免为了凑栏目重复每篇摘要或给出泛泛的研究建议。
```
