# 论文筛选规则

Paper Digest 面向关注不同方向的读者，覆盖 `config/research-interests.json` 中的全部方向。选文帮助读者了解本方向的新证据、值得借鉴的机制和重要争议；读者可以只读自己关心的部分。完整报告与方向综述长期保留，Idea 和实验计划作为可选的深入入口。

筛选时分别判断思想价值与证据成熟度：前者看问题、机制、数据或评测是否带来新的理解，后者看现有实验能支持多强的结论。成熟系统、有启发性的早期方法、可靠的负结果和基准工作都可以入选，不以同一套驾驶闭环要求衡量所有论文。

## 必须满足

- 首次收录的 arXiv ID 或标题不能已经出现在 `content/reported-papers.md`。既有论文的新版本或资源发布可单列为更新，不能换 ID 重复收录。
- 主题必须与至少一个配置方向有具体关系；邻域工作需说明可迁移的机制或问题，以及尚未验证的应用条件。标签匹配只是发现线索。
- 来源必须可核验，优先正式会议、期刊、OpenReview、CVF、arXiv、项目页或作者主页。
- 贡献必须可辨认：方法、数据、评测、理论分析或有依据的负结果均可，不能只有演示和笼统结论。综述主要服务系统学习与引文追溯，不包装成新的方法结果。
- 证据要与论文任务和主张相称。重建可由几何、视图合成与效率实验支撑，检测或预测可由对应基准与分析支撑；若主张驾驶决策、安全或部署改善，再核对相应闭环、真实系统或运行证据。未测的应用价值写作待验证的迁移判断。
- 入选理由必须能写成一句具体短评，不能只写“很新”或“效果好”。

## 检索与发布审计

- 每期必须保存 `content/digest-audits/YYYY-MM-DD.json`：记录真实查询串、端点、时间范围、每族结果 ID、去重候选台账、标题/摘要筛除、全文筛除及最终入选理由。简报中的原始命中、去重、全文阅读和入选数量必须能由该文件重算。
- “扫描窗口”按上期账本与本轮检索界定，不等于作者提交日期。若为覆盖 arXiv 审核或公告延迟而向前扩展查询，必须记录扩展范围和原因，不把较早提交的稿件写成窗口内新提交。
- 出版状态逐篇核验。已有正式论文页时同时保留正式页与 arXiv；只有 arXiv comments 声明录用、尚无正式页时写明 `accepted` 或 `workshop-accepted` 的证据边界，不写成已正式出版。
- GitHub 或项目页必须检查实际内容。只有 README、`coming soon` 或待发布声明的入口标为 `release pending`，不得写成“代码已开放”“数据已开放”或据此安排立即复现。
- 对容易漏检的方向做有边界的抽查：从标题规则未命中的记录、相关会议/综述追溯和读者补充中选取可复核样本，优先检查来源受限、长期未收录或过度依赖单一关键词的方向。记录样本 ID、抽样依据、实际阅读和发现的相关候选；发现漏项后修订同义词或查询并补查，保留已知漏项作为后续查询的回归样例。记录放入现有审计说明或相邻检索记录，不另建一套计数。有限抽查不估计全领域召回率，查询成功也不表示覆盖完整。

## 加分项

- 和规划、闭环评测、通信约束、V2X 时空同步、真实路侧设备、3D/4D 场景一致性、世界模型 rollout 或攻击防御链路直接相关。
- 给出代码、数据、模型、项目页或完整 benchmark 细节。
- 除本任务结果外，还解释对下游任务、效率或部署的影响；这是额外证据，不是所有表征或基础方法的入选前提。
- 雷达方向能说明点云、张量、Doppler、时序状态或跨模态监督怎样改善场景表示，而不是只把雷达特征拼接进已有检测器。
- 雷达占据工作区分 4D 成像雷达输入和 `x-y-z-t` 时空占据输出，并评价稀疏噪声、恶劣天气、标定误差或时间错位下的行为。
- 有清晰消融，能定位收益来自哪个模块。
- 对失败案例、边界条件或通信/计算预算有诚实讨论。

## 降权或剔除

- 将非驾驶、室内、游戏或纯语言结果直接包装成驾驶结论，且无法在报告中建立清楚的适用边界。机制有明确迁移价值时可作为邻域工作介绍。
- 用视觉质量、ADE/FDE 或检测 mAP 推导未经验证的规划、安全结论；这些指标若与原任务相符，本身不是降权理由。
- 已有方法的重复组合或指标微调，既未解释收益来源，也未提供有用的新问题、数据、比较或可复用机制。
- 对协同任务的通信、定位和时延假设影响主要结论，却缺少必要分析；仍可介绍假设明确的机制研究，但不能写成现实链路已经验证。
- 元数据不可靠、作者/来源无法核验，或内容明显由二次摘要站点拼接。

## 每期范围

- 每期通常 5 到 8 篇，优先级用于安排检索与编辑注意力，不代表每位读者必须阅读的顺序。兼顾近期已有覆盖和待跟进问题，证据不足时减少篇数，不为配比降低入选要求。
- 每个方向最多 1 到 2 篇，除非当期出现明显突破性论文。
- 通常兼顾方法、系统以及安全或评测视角，一篇可同时承担多个用途；专题简报可以集中于一个方向。根据实际候选取舍，不强行把不同读者的兴趣合成同一组实验任务。

上述安排用于比较候选，不能把缺少合格候选写成某方向“没有进展”。检索、独立筛选、写作、复核及发布的交接条件见 [写作与发布要求](publication-checklist.md)。
