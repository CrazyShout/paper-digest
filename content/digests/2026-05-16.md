## 本期判断

本期主线是自动驾驶研究正在把“信息更多”推进到“闭环是否更好、表示是否真实可用、输入是否可信”。MDrive 直接质疑 V2X 感知共享能否转化为闭环规划收益；MORPH-U 把延迟、丢包和伪造 V2X 消息纳入重规划防护；DUST 指出车路协同 4D 重建里的时间异步是表示层失败，不是调参问题。另一条线是数据和世界模型：VRS 从车端点云合成路侧 LiDAR，PointForward 用 point-aligned feedforward 表征减少重建 artifact，EponaV2 用未来图像、深度和语义推理支撑 planning。Temporal Sampling 和 Real-Time Adversarial Evaluation 则提醒训练协议和鲁棒性评测本身也会决定结论。

## 筛选口径

- 检索时使用 `config/research-interests.json` 中的 seed queries 和关键词，优先 2026-05-05 到 2026-05-14 的 arXiv 官方元数据。

- 优先选择能形成闭环证据链的论文：closed-loop benchmark、V2X unreliable message handling、cooperative 4D reconstruction、roadside data synthesis、future reasoning for planning 和 adversarial robustness。
- 同主题但本期未入选的世界模型论文包括 CoWorld-VLA、DeepSight 和 DriveFuture；它们很相关，但本期保留 EponaV2 作为最新 future-reasoning 样本，避免世界模型占用过多篇幅。
- 降权只展示视觉生成质量、只做单一开环指标、或缺少对下游规划、安全和部署约束解释的论文。

## 应用场景与讨论线索

- 闭环协同评测：MDrive 和 MORPH-U 应一起读。前者给出 closed-loop cooperative benchmark，后者给出带 V2X 消息验证和 Pareto tuning 的鲁棒规划栈。
- 协同数据资产：DUST、VRS 和 PointForward 可以组成重建与数据生成路线。DUST 解决车路异步动态 agent 的 ghosting，VRS 解决路侧 LiDAR 数据稀缺，PointForward 解决快速重建中的跨视角一致性。
- 可规划世界模型：EponaV2 与 DAWN 形成对照。DAWN 强调 world-action 递归交互，EponaV2 强调未来图像、深度和语义监督对 perception-free planning 的作用。
- 评测变量本身：Temporal Sampling 和 Real-Time Adversarial Evaluation 都不是单纯新模型，而是提醒实验必须报告采样频率、模型容量、状态表示和攻击设置，否则 nominal 指标可能掩盖真实风险。
