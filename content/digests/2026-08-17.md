## 本期判断

本期最清晰的主线不是模型规模继续增加，而是研究者开始追问：输入、动作、场景和评测结论究竟是不是同一个可核验对象。`How Can Driving World Models Do Counterfactual Prediction?` 指出，世界模型只看共享历史和备选动作时，生成的是某个合理未来，并不保证保留这次事件事实中后来出现的车辆；作者用 186 组 CARLA 配对世界把反事实从视频展示变成可量化问题。SSP 在评测端处理同一种混杂：Synthetic、Simulation 和 Physical 若只共享“cut-in”标签而不共享角色、冲突关系和事件阶段，所谓 domain gap 很可能只是样本难度不同。两篇论文共同把“同一事件”提升为世界模型和跨域测试的首要准入条件。

端到端驾驶的热点则从“把语义和预测都接进来”转向接口与计算路径。BrainWAM 发现 VLM、视频生成和 action token 的原始联合注意会让语义捷径压制预测动力学，因此保留两条专门通路，只在 action 表征上协调；FlashDrive 则把 VLA 控制循环拆成 Encode、Prefill、Decode 和 Action 四段，分别复用跨帧上下文、并行草拟低熵推理 token、缓存 flow-matching 中段速度，再叠加系统优化，把 Alpamayo 1.5-10B 从 717 ms 降到 151 ms。前者说明“融合位置”会决定模态是否真正互补，后者说明“模型能够输出轨迹”与“轨迹能按控制频率输出”是两个独立门槛。

测试方向开始认真处理廉价证据是否迁移。Coverage-Aware Active Evaluation 不假设 simulator 或小模型的失败必然属于目标系统，而是用少量 target evaluation 校正 proxy 风险，在相关性弱的 nuPlan 区域自动降低代理权重；同时用互信息与聚类兼顾新区域和失败模式多样性。SSP 再把 broad synthetic screening、CARLA controlled replay 和 proving-ground confirmation 串成三层证据链。共同结论是：便宜的生成或仿真证据适合扩大覆盖，但只有记录“哪一类场景、以多大相关性、经过何种物理确认”后，才能进入安全判断。

场景表示方面，本期三篇论文从不同层次反对“原始输入天然可信”。RbFT-Net 不把多帧 4D 雷达叠加当作更密的真值，而是先校正投影位置和 metric depth，再估计逐点 reliability 后选择性传播；GeoUP 不让每个感知 head 各自在二维语义骨干上重建三维空间，而是从 VGGT 的重建 latent 出发，让 depth、3D detection 和 semantic occupancy 共享 metric geometry；LGS 则不再把 LiDAR 初始化的 Gaussian 数量视为固定结构，用 prune/add 干预产生可学习的密度决策。三者分别在量测、latent 和 primitive set 层显式管理“什么证据值得保留”。

对“雷达中心的时空占据与场景表征”而言，RbFT-Net 是本周最直接的新证据，但它解决的是相机视角 metric depth completion，不是三维时空 occupancy。它真正可借鉴的是：跨帧回波增加密度的同时也增加错位、动态干扰和 multipath，可靠性必须在稠密传播之前建模。GeoUP 则提供 surface-instance-volume 的统一读出范式，但仍是 camera-only。可做的下一步不是把二者标题拼在一起，而是让 radar anchor reliability 显式决定 occupancy 中 occupied/free/unknown 的证据权重，并在恶劣天气、跨平台和未来流预测中检查校准是否保持。

- 统一使用八项等权量表：方向相关性、问题意义、方法新意、实验闭环、证据现实性、公开资产、局限透明度，以及对部署或后续研究的影响。7.5 为录用线，不按方向配额补齐；本期 8 篇通过，分数范围 8.3-9.2。
- 优先保留有可反驳主张和明确实验端点的论文：配对反事实真值、端到端 wall-clock 与闭环 rollout、proxy-target 相关性、同事件三域执行、跨传感器平台、跨数据集几何与结构消融。只给通用框架、弱代理分数或无法确认任务终点的候选降权。
- `LLM-Assisted Dynamic Threat Analysis` 的 185-package Autoware 静态盘点很有价值，但 37 次 crash 全来自 stub，预算内没有动态确认真实 weakness，因此作为负结果线索保留在候选池而不进入本期正式 8 篇。只有模型宣称安全、没有闭环或真实故障端点的 VLA 工作同样未录用。
- 本周没有汽车 V2X/协同感知论文达到门槛。检索到的直接 cooperative perception 新稿集中在海事或通用通信任务，无法提供车路协同感知、规划或真实链路的新证据，因此不为方向覆盖硬加条目。
- 每篇详细报告均核对 arXiv HTML/PDF 首页、作者单位、数据集、指标、关键数字和 limitations，并放入两张论文官方图。扫描时仅确认 arXiv 的论文不写成已正式录用；存在项目或代码页时单独保留入口。

## 可靠性评估

- **9.2 | Counterfactual World Models**：问题定义、配对基准和错误 episode/time 对照形成闭合证据链；主要风险是短时脚本化他车和 CARLA 域。
- **9.1 | FlashDrive**：端到端时延、跨 GPU、开环精度、闭环指标和开源资产齐全；wrong-lane 回归与车规硬件尾延迟仍需复测。
- **8.9 | Coverage-Aware Active Evaluation**：四类系统、proxy 失效边界和组件消融充分；效果依赖场景嵌入，部分任务 seed 数较少。
- **8.6 | SSP**：同事件三域和封闭场地证据少见，局限披露完整；当前只有两类事件，公共资产仍待发布。
- **8.5 | BrainWAM**：融合失败诊断、单分支/三模态/动作级对照清楚；计算成本高，主要终点仍是 NAVSIM。
- **8.5 | RbFT-Net**：公共集、新平台、零样本和少样本适配同时验证；新数据未开放，任务不是 occupancy。
- **8.4 | GeoUP**：五数据集覆盖和三任务消融强，几何 latent 结论可信；骨干较重、occupancy 监督只来自 nuScenes。
- **8.3 | LGS**：干预监督、同 Gaussian 预算随机对照和双数据集结果扎实；推理约 1.9 s，缺少策略与传感器闭环。

## 应用场景与讨论线索

- 反事实测试：把完整事故日志、备选轨迹和可反应参与者放入同一 causal replay；先判断哪些事实可搬运，再让世界模型生成真正未知的部分，避免把“重新采样未来”误称为事故反事实。
- VLA 部署：建立四阶段 profile 与状态缓存审计，重点测丢帧、多相机异步、缓存年龄和 p99；把 FlashDrive 的运行时信号与 BrainWAM 的按需预测分支结合，困难场景恢复完整计算。
- 分级验证：用大规模生成/低保真仿真做 coverage search，以 Coverage-Aware 方法估计 proxy-target 迁移度，再按 SSP 事件规格进入 CARLA 和封闭场地确认，形成可追溯的测试漏斗。
- 雷达 Occupancy：将 RbFT-Net 的位置、深度与 reliability 输出改造成三维 evidence anchor，分别更新 occupied、free 和 unknown；与 camera/LiDAR 教师冲突时不立即融合，而是记录天气与可观测性条件下的校准误差。
- 统一场景表示：借用 GeoUP 的 surface-instance-volume 共享 latent 和 LGS 的结构干预，把新增 query/Gaussian 的监督从 PSNR 扩展到 occupancy 边界、传感器渲染一致与规划行为变化。
- 组会讨论：当廉价 proxy、生成世界模型和真实系统给出冲突结论时，应该由平均准确率、局部相关性、事件身份还是最坏安全后果决定证据优先级？
