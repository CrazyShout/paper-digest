## 本期判断

本期八篇覆盖真实 C-V2X 数据、协同到单车蒸馏、VLA 提示、世界模型和测试。CooperScene 与 C2E 可比较在线通信和离线训练的作用；CommonRoad-Game 与 TrafficAlign 提供两类场景来源；LiDAR 鲁棒性报告则按误检、漏检和几何偏差拆开性能。

## 论文对照

本期从通信数据、模型输入和测试场景三个方面比较驾驶系统。CooperScene 把 C-V2X 真实通信链路拉进 benchmark，C2E 反过来问协同感知收益能否蒸馏回不通信的 ego-only 检测器；DriveTeach-VLA 和 X-Mind 分别设计驾驶模型的推理输入，一个用 2D trajectory-guided prompts 教模型看哪里，一个用 predictive world model 让模型在动作前先想象未来；CommonRoad-Game 和 TrafficAlign 则把测试场景来源从静态数据集扩展到人机交互和真实视频对齐的 LLM 生成；LiDAR 鲁棒性分析指出感知 benchmark 如果只看 mAP，会掩盖攻击下的误检、漏检和几何偏差。

## 应用场景与讨论线索

- V2X 与协同：CooperScene 适合讨论真实 C-V2X 链路下的协同感知 benchmark，C2E 适合讨论“在线协同”和“离线蒸馏”的部署取舍。
- VLA 与世界模型：DriveTeach-VLA、X-Mind、CascadeOcc 分别代表空间提示、未来视觉思考和占据 token 三条路线，可放在一起讨论驾驶大模型到底需要什么中间表示。
- 测试与场景生成：CommonRoad-Game 和 TrafficAlign 都把测试场景从静态数据集里解放出来，一个依赖人类交互，一个依赖真实视频和 LLM 对齐。
- 安全与鲁棒：LiDAR 鲁棒性论文提示后续筛选不能只看正常指标，应该记录 attack success rate、false negative、localization error 和距离/点云密度分层。
- 组会讨论：本期共同问题是“更强模型是否必须配套更真实的数据、通信和测试接口”，否则模型分数提升很容易和部署风险脱节。
